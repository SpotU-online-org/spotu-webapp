## ¿Qué es cada documento?

### [SpotU_Presentacion.pptx](SpotU_Presentacion.pptx)
Presentación visual de 14 slides con la propuesta resumida. Ideal para una primera reunión presencial o remota. Cubre: problema, solución, mercado, modelo, equipo, roadmap y cierre.

### [pitch.md](pitch.md)
Versión textual del pitch. Contiene la narrativa completa: problema, solución, estado actual del MVP, mercado, modelo de negocio, posicionamiento competitivo, roadmap, equipo y FAQ.

### [team.md](team.md)
Quiénes están detrás del proyecto y qué perfiles complementarios buscamos. Aclara que el reparto de equity aún está abierto.

### [business_model.md](business_model.md)
Cómo SpotU genera revenue: tarifas, programa de pioneros, unit economics, proyecciones de MRR y break-even. Pensado para inversores/socios financieros.

### [market_study.md](market_study.md)
Análisis del mercado publicitario LATAM, panorama competitivo (PRODOOH, Hivestack, MiQ+Adsmovil, Publimovil, Sortlist, AdQuick, etc.) y posicionamiento honesto de SpotU dentro del ecosistema. **Importante:** SpotU coexiste con jugadores fuertes — no llega a un mercado vacío.

### [website_guide.md](website_guide.md)
Explicación sin tecnicismos de cómo funciona la plataforma. Útil para socios no-técnicos o para mostrar el producto a alguien antes de la demo en vivo.

### [branding.md](branding.md)
Identidad visual y voz de marca: paleta, tipografía, iconografía y reglas de comunicación.

### [glossary.md](glossary.md)
Glosario de términos (SMB, OOH, DOOH, ARPU, MRR, etc.) para consultar cuando aparezca algún concepto desconocido.
